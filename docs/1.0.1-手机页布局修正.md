# 1.0.1 手机页布局修正

任务卡从所有页面的公共顶部移到独立的“任务”标签页。手机页保留设备选择、画面、右侧操作按钮和文字输入区；任务记录、进度、停止、最近截图和继续草稿只在任务页显示，结果页也不再受任务卡挤占。

新增任务页状态持久化，原有手机、结果、调试页面选择仍兼容。任务结果按钮仍能跳到准确报告并清空不相关筛选。

已通过类型检查、4 项既有状态存储测试、带历史任务的 360 / 480 / 860 像素真机布局检查，以及任务切换、延迟轮询、停止目标、继续草稿、旧报告定位与删除链接的界面回归。手机页的任务卡不可见，画面区域高度超过测试窗口的 60%，切换任务页后能查看任务详情，切回手机保留连接。没有重新执行与布局无关的应用采集流程。

当前桌面版在无活动手机任务时正常重启加载 1.0.1，实时画面 streaming、查看端 1，原有 3 份报告文件校验值保持不变。证据：`.build/evidence/layout-phone-480.png`、`layout-tasks.png`、`task-ui-smoke.json`、`desktop-101-delivery-health.json`。
