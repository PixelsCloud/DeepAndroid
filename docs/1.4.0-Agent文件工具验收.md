# 1.4.0 Agent 文件工具验收

交付日期：2026-10-26。环境：Windows、DeepSeek Harness Desktop 0.2.1-rc.2、Redmi K40S / Android 14、USB ADB。

## 交付范围

新增七个原生 Agent 工具，总计 39 个模型可见工具。继续使用 Harness 自身工具运行时，没有新增独立 MCP 进程、模型循环或面板按钮。`dsh-android/agent` 在没有 WebServer、浏览器和面板时也能注册同一套能力。

| 工具 | 行为 |
| --- | --- |
| android_file_stat | 确切路径的存在性、类型、大小、时间、指纹，可选 SHA-256。仅实际 ENOENT 返回 not_found，权限错误不冒充不存在。 |
| android_file_manage | mkdir / copy / move / rename / delete，默认不覆盖，目录递归须明确指定。单文件复制先比对源与暂存哈希再提交；目录复制不是变化中源目录的原子快照。 |
| android_open_file | 通过正常 MediaStore URI 与临时只读授权请求应用打开文件，可指定 MIME、包名；须观察确认实际内容。 |
| android_share_file | 将文件交给系统分享入口或指定应用，不选择联系人、不点击发送、不宣称送达。 |
| android_wait_file | 有界等待文件存在或变化并连续稳定，支持旧指纹排除、最小大小与时间条件；稳定不代表生产应用已完成写入。 |
| android_transfer_status | 查询实际 job_id 或近期传输/安装记录，返回状态、阶段、实际路径、已知大小、哈希及错误，不虚构百分比。 |
| android_transfer_cancel | 取消确切任务，查询最终状态；重复取消幂等，已结束任务不会被撤销。 |

push / pull 增加 `wait:false` 返回后台 job_id。后台传输最长 5 分钟，创建它的工具调用或 Agent 回合结束后仍继续；插件关闭请求取消。取消不保证回滚，原进程未结束记录在重启后标为 failed / interrupted / outcome_uncertain。

路径按字面值处理，拒绝控制字符、上级路径和存储根目录修改。文件管理作用于共享存储或 `/data/local/tmp` 的具体子路径。目录操作最多 1000 项、32 层、累计 2 GiB；单文件最大 2 GiB。复制不跟随符号链接；删除末尾链接本身。实际系统拒绝访问则返回错误。

## 自动验证

类型检查、构建、157 项自动测试全部通过，新增 12 项文件工具测试，覆盖：路径与根目录边界、ENOENT/EACCES 区分、超大数字保真、哈希中源文件变化、旧文件排除与稳定等待、等待取消、链接删除边界、后台调用生命周期、重启不确定性、只读 URI 授权、Android 用户切换、真实 Harness ToolRuntime 的启动/查询/取消/幂等调用。

## 真机验收

`scripts/agent-files-smoke.mjs` 从无面板 Agent 入口加载实际 Harness ToolRuntime，核对 39 个模型可见工具，并进行 49 次原生工具调用。只操作自有 UUID 测试目录和生成文件，不发送聊天、不调用模型、不安装 APK。

- 创建目录、重复创建幂等；上传包含中文、空格、引号、美元符、&、# 和字面 `%20` 的图片路径，SHA-256 一致。
- 复制、同目录改名、跨目录移动、递归目录复制正确；未授权覆盖、非递归删除非空目录和存储根目录删除被拒绝。
- 本机 MIUI 的 ADB sync 对测试符号链接 lstat 返回 EACCES，工具如实报错，没有改用提权或权限绕过。测试夹具通过正常 shell 删除自身创建的链接；原图片哈希不变。链接删除语义由单元测试独立覆盖，不把此项冒充真机链接删除成功。
- 等待已存在文件连续稳定，明确 `completion_guaranteed=false`；原指纹未变时超时；在等待期间产生的新文件正确被发现并稳定。
- 正常 MediaStore 扫描与精确路径查询找到测试图片，临时只读 URI 交给 MIUI 相册。截图人工核对显示生成的深青色背景和金色方块。
- 分享调用进入 MIUI 系统分享选择界面，截图核对正确；没有选择接收方或发送，返回 delivery_confirmed=false。
- 后台 pull 返回任务 ID，最终 completed，本机实际文件与源 SHA-256 一致。
- 32 MiB 自有随机文件的后台 push 到达 transferring 阶段后取消，最终 cancelled / outcome_uncertain；重复取消返回 already_finished。对已完成上传请求取消保留 completed，原图片不变。
- 自有测试目录被清理；最后回到 `com.miui.home`，键盘隐藏，释放会话操作。

系统 DocumentsProvider 对 shell 的正常权限拒绝未被绕过；最终采用正常 MediaStore 内容 URI，不使用裸 file URI 启动接收应用。文件未被媒体提供器收录或无应用能处理时可能失败，返回实际原因。USB 安装仍受手机既有策略限制，本阶段不依赖辅助 APK。
