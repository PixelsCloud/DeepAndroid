# 人工控制开发与验收记录

版本：0.2.0。状态：代码及真机控制测试通过，已更新当前 Harness 桌面并保持自动连接。

## 功能

点击、长按、拖动、滑动、滚轮、右键返回、返回/主页/最近任务/唤醒按钮、英文键盘输入、方向键、退格、Enter、Ctrl+A，以及通过手机剪贴板发送中英文多行文字和 emoji。

输入按设备串行处理；坐标携带视频尺寸和画面代次；旋转后拒绝旧坐标；窗口失焦、指针捕获丢失和会话结束时释放触点。注入错误显示在控制提示中，不主动终止视频。

## 桌面验证范围

当前 Harness 桌面已确认实际加载、自动连接、视频显示及控制按钮启用。完整指针与文字控制用例在共用的浏览器面板上通过；Windows 桌面输入辅助工具返回 coordinate input geometry is unavailable，因此未宣称完整桌面指针用例已通过。

强制结束进程及带调试参数启动被自动审批拒绝。最终通过 Windows Restart Manager 的非强制正常关闭方式更新应用，并以普通方式启动。当前保持手机主页画面，供用户直接操作。
