# 0.8.0 结果管理

在“结果”页增加重命名、删除、搜索、日期筛选和分页；继续保留手机与调试页，以及 16 个原生工具。

- 重命名只修改标题。原保存时间、表格、截图依据及结果 ID 保持不变，后续导出使用新标题。旧版结果兼容加载，工具调用重试不会覆盖用户改名。
- 删除移入“最近删除”，可立即撤销，也可重启后恢复。普通查看、截图和导出不访问已删除结果。删除不清理报告 JSON 或 Harness 附件，不提供永久清空功能；相同调用重试不会把已删除结果重新创建。
- 搜索覆盖标题、摘要、列名、单元格、行说明及未完成原因，按普通文字匹配，支持大小写与全角字符归一化。日期按浏览器本地日历日期换算成 UTC 边界，包含所选开始、结束日期；无效范围会明确提示。
- 每页 20 份，可翻页查阅历史。历史搜索不再受之前 100 份显示上限限制。清空筛选会清空关键词和日期，保留当前“全部结果 / 最近删除”范围。
- 输入防抖与查询版本校验避免旧响应覆盖新搜索；较早查询延迟失败也不会污染新结果。修改操作顺序写入，先落盘再更新内存。
