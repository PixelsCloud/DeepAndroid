# 0.6.1 共享操作

按用户要求移除“人工接管 / 允许 Agent”按钮及其权限状态，不再按操作者保留手机控制权。手动输入与各个对话均可直接操作。

- 工具调用仍按顺序执行；调用结束即结束本次占用，不要求其他对话等待显式释放。
- 手动输入中断当前冲突动作，等待旧触点释放后执行。Agent 收到 INPUT_INTERRUPTED 提示，直接重新观察即可继续；不会进入等待允许的状态。
- 手动拖动时，排队的工具只等待抬手，不需要授权。观看端关闭会清理自己的触点，不中断其他对话正在执行的动作。
- 任意输入使旧观察失效。取消、释放、Agent 空闲或销毁只清理对应对话，不影响其他对话。
- 断线后可以面板重连，也可以由新的原生工具调用建立连接；不再要求点击允许按钮。

验证：类型检查、构建、70 项自动化测试通过。真实 USB、原生 Harness ToolRuntime 与实际面板回归通过：界面无两个控制按钮；手动主页打断手势后另一对话立即操作；旧观察被拒绝；取消、会话清理、面板重开和模拟视频断线重连正常。测试结束返回手机桌面。

最终 `.tgz` 在独立 profile `android-061-final` 安装并运行通过，15 个原生工具与 WebCodecs 视频正常，无浏览器未处理错误。当前桌面已正常重启加载 0.6.1，确认实时视频 576×1280，旧控制按钮不再出现在已加载的 UI 中。
