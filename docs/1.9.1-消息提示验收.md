# 1.9.1 消息提示验收

日期：2026-10-27。

## 交互

- 右上角浮动 toast，支持多条消息，每条右上角都有关闭按钮。
- 错误使用红色样式与 alert 语义，必须手动关闭；等待、连接恢复、切换页面、后续操作成功都不会自动移除已有错误。
- 普通提示使用绿色图标与 status 语义，5 秒后自动消失，也可提前关闭。鼠标悬停或键盘焦点进入时暂停计时，离开后继续剩余时间。
- 相同可见消息合并，后台持续故障使用来源标识避免关闭后立刻重弹；显式重试或恢复后再次失败可重新提示。
- toast 使用浏览器顶层，并在打开原生 dialog 时归属当前对话框，确保关闭按钮不会被 modal 的 inert 行为阻止。对话框关闭后提示仍保留。
- 文本通过 textContent 显示；长路径换行并在卡片内滚动，360 px 窄面板无横向溢出。动画尊重减少动态效果设置。面板卸载后清理 DOM、监听器与计时器。

接入范围：手机连接、面板状态保存、手机输入、文件管理与相关对话框、更多操作、任务反馈、结果管理和调试页操作反馈。实际目录错误状态、失败作业详情、连接状态、诊断报告与可撤销操作继续保留，方便查看当前业务状态。
