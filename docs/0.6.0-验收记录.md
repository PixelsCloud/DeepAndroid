# 0.6.0 复杂任务可靠性验收

环境：2026-10-24，Windows、Harness 0.2.1-rc.2、USB Redmi K40S / Android 14。沿用 Harness 原生 Agent 循环，工具由 11 个增加至 15 个。

## 交付功能

- `android_tap_target`：按文字、资源 ID、类名、包名等条件重新观察定位。只在完整元素树中唯一匹配时按一次；零个或多个匹配项不按。后续最多观察 3 次，支持目标条件验证；条件点击前已存在时不作为成功证明。未确认成功也不会自动重按。
- `android_wait`：等待目标出现、消失、界面变化、连续两次稳定。最多观察 8 次，不发送输入。稳定不代表网络完成；消失仅指已暴露的完整元素树。
- `android_scroll_find`：在明确的滚动区域内查找，最多滚动 7 次，找到后不点击。多区域需要精确选择，允许按资源 ID（含空 ID）与类名组合选择。
- `android_read_list`：按实际标题锚点跨屏采集，最多 100 条、8 屏。去重并返回原始行文字；行结构有歧义时只提供标题。相邻屏必须有重叠标题，否则以 `continuity_lost` 停止并保留之前结果。通过慢速拖动、停留后抬手降低惯性跳项。
- 任务记录可查看结构化读取结果与每屏截图。视觉模型收到按页排序的原生截图附件，同一页不重复附加；文字模型收到元素与原始行文字。
- 组合操作在同一设备控制锁内执行，受人工接管、取消、整轮限额和单次 120 秒时限约束；中止时释放触点。保留原有 11 个工具行为。

## 验证结果

1. 类型检查、构建、66 项自动化测试通过。新增覆盖目标歧义、不重复点击、条件已存在、有限等待、截断树、跨屏去重与行归属、滚动区域歧义、选错页头区域、无 ID 容器、页面变化、漏项连续性、取消与接管、每屏证据持久记录、原生多图渲染。
2. 知乎真机：从实际热榜入口定位顶部，跨屏采集 20 个唯一标题及原始行文字；逐项核对元素树明确提供的排名 4–20 无跳号。前 3 项排名图标不在元素树中，保留截图供视觉核对，不由工具推测。打开其中一条，确认详情标题可读，返回桌面。原始证据：`.build/evidence/zhihu-list-smoke.json` 及 `zhihu-list-*.png`。
3. 系统设置真机与实际记录面板：定位进入设备信息页、跨屏读取 20 条菜单、反向查找、稳定等待、找不到目标时有界停止、查看列表第 2 屏截图。证据：`.build/evidence/navigation-smoke.json`、`navigation-records.png`。
4. 既有人工接管、取消、重连和明确允许后的恢复回归通过。中文“电池”“显示”搜索、替换查询及不存在目标的有限查找回归通过。
5. `.tgz` 安装包已通过正式安装器装入独立 profile `android-060-final`，实际运行目录位于用户 profile，未链接开发目录。独立诊断器自动识别 ADB、15 个工具正常注册、WebCodecs 真机视频正常、浏览器无未处理错误。证据：`.build/evidence/release-smoke.json`、`release-installed-panel.png`、`release-060-sha256.json`。
6. 当前用户桌面经正常退出重启加载 0.6.0。交付检查：15 个工具、576×1280 实时视频、1 个查看端、诊断 READY、无 Agent 占用，手机停在桌面。证据：`.build/evidence/desktop-060-delivery-health.json`。

首次知乎快速滚动测试读到了 20 个标题，但逐项检查发现漏过一个排名。已用慢速滚动及相邻屏连续性检查修复，并重新核对排名通过。系统设置搜索回归曾因应用恢复到上次滚动位置而找不到顶部入口；测试现通过原生向上查找恢复入口，不重置应用数据。

## 使用与边界

可在 Harness 聊天中验收：“使用 Android 原生工具打开知乎，读取热榜前 20 条，整理排名、标题和热度；打开其中一条读取摘要，最后返回桌面并释放控制。字段缺失或列表不连续时明确说明。”

实际成功率仍取决于 App 暴露的元素结构与当前模型；自绘、截断或不暴露元素的页面不会盲目自动翻页。按标题去重可能合并同名条目；热榜是实时内容，多屏观察不代表同一时刻的全榜快照。`unchanged`、`no_new_items` 不证明到达列表真正末尾。

本轮测试直接调用实际 Harness ToolRuntime 与真机，未代发用户桌面聊天、未调用模型生成摘要。测试应用安装被手机拒绝后，改用已安装的设置和知乎完成验证。
