# 1.5.0 Agent 媒体与文件选择验收

交付日期：2026-10-26。环境：Windows、DeepSeek Harness Desktop 0.2.1-rc.2、Redmi K40S / Android 14、USB ADB。

## 交付范围

落实本阶段优先的两个工具，总计 41 个模型可见的原生工具，不增加面板按钮、独立 MCP 服务或模型调用。Host 与无面板 `dsh-android/agent` 入口提供相同能力。

| 工具 | 行为与边界 |
| --- | --- |
| android_media_query | 正常权限下读取当前用户 MediaStore 图片、视频、音频索引；按字面名称子串、共享目录（含子目录）、修改时间筛选。默认 10 项，最多 20 项，按修改时间与 ID 倒序，使用实际游标分页。返回名称、路径、MIME、大小、时间和可用的尺寸/时长。索引不是文件当前存在或完整的证明；需要时另查 stat。 |
| android_pick_file | 操作调用应用已经打开的系统 DocumentsUI PickActivity。inspect 返回可见行与截图；select 可搜索确切名称并点击一次。前台、焦点、完整结构、已有选择、重名、不可用行及滚动隐藏结果都有检查。保留调用应用原本的文件回调，不另起选择器或向应用注入 URI。 |

媒体查询不触发扫描、不读取文件正文、不启动视频或打开应用。只接受结构化参数，没有原始 SQL 或任意内容提供器接口。数字列的输出在手机侧有界；文字列分别查询并以 Base64 分隔，文件名中的逗号、字段名、引号和换行不能冒充元数据边界。筛选转义 SQL 引号及 LIKE 通配字符。Android 用户在查询前后不一致则丢弃整次结果；错误不冒充空列表。

选择器目前仅支持 `com.android.documentsui` 与 `com.google.android.documentsui` 的 PickActivity，焦点也须属于同一应用。厂商相册、系统 Photo Picker 和普通文件管理活动返回 not_picker。浏览器可能先显示“相机 / 媒体”，Agent 可用普通界面工具进入媒体后再调用。

选择器按显示名称操作，不从名称推断真实文件路径；应先导航到正确目录。列表仍可滚动时不自动选择，以免遗漏屏外同名项。已有选择或选择模式阻止追加，避免带入别的附件。多选确认不会自动点击。selection_requested 仅表示匹配行被点击，`attachment_confirmed=false`、`upload_performed=false`，不能据此宣称正确附件已上传；须观察调用页面。工具不点击发送或发布。

系统搜索框实测为 AutoCompleteTextView，已修正通用界面解析，使空的、聚焦的 AutoCompleteTextView 及其多选变体也被识别为可输入控件。保留密码遮蔽、聚焦要求、观察消费、坐标缩放和中断释放规则。原始 XML 仅在选择器内部解析，不放入工具 JSON 或其他观察结果。

## 真机工具链

`scripts/agent-library-smoke.mjs` 使用无面板 Agent 入口与实际 Harness ToolRuntime，共 27 次原生调用。仅操作自身 UUID 目录与生成文件，使用一条自有端口的 ADB reverse 和仅本机监听的 HTML 文件输入控件。不安装 APK、不发送 Harness 聊天、不调用模型、不向外部上传内容或点击发送。

- 41 个工具进入模型可见清单；在桌面调用选择器工具返回 not_picker，没有点击。
- 自有目录内两张生成图片被正常媒体索引收录。字面筛选命中包含中文、引号、下划线、& 与 % 的名字；图片实际为 320×320、1021 字节。
- 相同修改时间的记录按 ID 稳定排序，limit=1 的两页返回不同 ID，末页 has_more=false；视频类型筛选最初返回零条图片匹配。
- 测试阶段使用本机 FFmpeg 生成蓝色视频和正弦音频，正常上传并扫描自身文件。查询得到视频 320×240、1200 ms，音频 250 ms，音频宽高为空。FFmpeg 仅为测试夹具依赖，插件运行不需要 FFmpeg。
- 手机 Chrome 打开本机测试页面。原生工具点击文件输入入口，先进入系统“媒体”，确认实际 DocumentsUI PickActivity。
- 新工具搜索唯一生成图片名称并点击一次，选择器关闭并返回 Chrome。HTML 文件输入控件独立报告实际文件名、1021 字节和 SHA-256，与原始图片一致。截图核对页面展示“已选择”及正确文件名。
- 源图片 SHA-256：`6bc807ef363a301aef3e5d1c4847f57189d1aa754a79fa147ecf926096adaa72`。
- 自有测试目录、HTTP 服务和 reverse 映射清理完成，最后返回 `com.miui.home`、键盘隐藏并释放会话操作。

这是实际工具调度和文件回调验证；不同应用、提供器、系统版本及自然语言选工具仍应由用户在 Harness 聊天中验收。没有把厂商相册或 Photo Picker 计为已适配。
