# 0.5.0 任务复用与交付验收

日期：2026-10-24。环境：Windows、Harness Desktop / CLI 0.2.1-rc.2、USB Redmi K40S / Android 14。

## 交付内容

- 保持 11 个原生手机工具；新增功能通过现有 Harness 工具结果、Agent 生命周期和会话事件接入，不增加第二套模型循环。
- ADB 自动发现与独立 `dsh-android-doctor`。区分缺少 ADB、ADB 无法运行、未授权、离线、断线、输入权限、焦点缺失、旧观察与模型图片能力等情况，附恢复说明。
- 面板提供连接诊断、任务记录、常用任务三个入口。设置支持 ADB 路径、每轮调用次数和时限；修改 ADB 路径前必须断开。
- 默认每轮手机任务最多 100 次原生调用、10 分钟。计时覆盖工具间的模型处理。达到上限会通过 Harness 的 hook 取消当前活动并中止手机动作、释放占用。调用释放工具不能重置预算，Agent 真正回到 idle 后下一轮才有新预算。
- 记录最终工具结果、时间、失败原因及截图引用。动作可关联操作前与后续观察截图；用户在模型处理期间按停止，也会记为取消。输入正文在本面板日志中省略，仅记长度；Harness 原始对话保持其自身记录规则。
- 内置设备信息、应用内搜索、多屏榜单读取模板。支持自定义参数模板，生成可审阅的任务草稿后复制到 Harness 聊天发送。
- 持久数据与程序包分离，默认位于用户 Harness 目录的 `android` 子目录。模板、设置和日志可迁移；图片原件由 Harness 附件服务持有。

## 已通过的验证

1. 类型检查、构建与 47 项自动化测试。覆盖调用预算、超时、中途取消、释放不能绕过限额、参数正文省略、截图关联、记录恢复、模板替换与保存、管理接口校验、旧 CLI 在修改 profile 前被拒绝。
2. `test:management`：真实 USB 手机、真实 Harness ToolRuntime、实际管理面板按钮共用一个设备服务。4 次调用后拒绝第 5 次手机动作并释放控制；面板显示原因且可查看实际截图；模板填写、复制、自定义保存有效且不会自行执行；设置可保存；实际观察超时被取消；服务重启后恢复设置、模板、3 项任务记录及截图依据。浏览器无未处理错误。
3. `test:search`：中文“电池”“显示”查询与替换、目标缺失的有限查找、返回手机桌面，回归通过。
4. `test:recovery`：人工接管、取消、多对话释放、面板重开复用、模拟视频连接丢失、明确重连和允许后恢复，回归通过。
5. 通过正式安装器在独立 profile 安装 `.tgz`，加载实际安装目录下的 Host 与 UI。独立诊断器自动找到本机 ADB；正常注册 11 个工具；真实手机视频通过 WebCodecs 显示为 576×1280；内置模板可读取。已验证运行位置在用户 profile，未使用开发目录链接或兼容性豁免。

原始证据位于 `.build/evidence`：`management-smoke.json`、`management-records.png`、`management-restored.png`、`release-smoke.json`、`release-installed-panel.png`、`search-smoke.json`、`recovery-smoke.json`。测试数据目录在 `.build/tests`，不打入安装包。

最终包已在 `android-050-final` 独立 profile 完成安装及视频验收。当前桌面已通过正常退出重启加载 0.5.0；交付检查确认 11 个工具、1 个画面查看端、576×1280 实时视频、无报错、无 Agent 占用，诊断为 READY。默认限额为 100 次调用、600000 毫秒。证据：`.build/evidence/desktop-delivery-health.json`。

## 安装兼容性处理

本机同时存在 PATH 中的旧全局 CLI 0.2.0-rc.2 和桌面自带 CLI 0.2.1-rc.2。首次安装被版本检查拒绝并回滚；随后识别到旧 pnpm store 与桌面安装器 store 不匹配。安装脚本已改为优先使用桌面 CLI，并在创建或修改 profile 前核对 SDK 版本。验收改用全新隔离 profile，没有修改原桌面 profile 的依赖 store，也没有授予版本风险豁免。

## 使用与边界

安装包仍要求目标电脑安装匹配的 Harness 与 Android Platform-Tools。ADB 自动发现不代表已随包分发完整 Android SDK。实体 USB 拔插、其他品牌手机以及不同模型的任务成功率需继续积累，当前不宣称全面通过。

模板生成的是草稿，需要用户粘贴到聊天并发送；不会隐式创建任务或定时运行。最新 100 项记录在面板可查看，磁盘旧记录不自动删除。来自其他或先前进程的未结束记录标为结果待确认。

用户已确认上一阶段桌面任务、人工接管、取消、中文搜索及知乎热榜滚动读取可用。本轮没有代发用户的桌面聊天验收；更新后可直接执行既有任务，再查看新记录和模板入口。
