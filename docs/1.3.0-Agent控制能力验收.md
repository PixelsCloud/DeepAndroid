# 1.3.0 Agent 原生控制能力验收

交付日期：2026-10-25。环境：Windows、DeepSeek Harness Desktop 0.2.1-rc.2、Redmi K40S / Android 14、USB ADB。

## 交付范围

新增五个模型可见的原生工具，总计 32 个。继续使用 Harness 自身 Agent 循环，不增加 MCP 进程或模型调用，不增加手机面板按钮；独立 `dsh-android/agent` 入口也注册同一套能力。

| 工具 | 行为与结果 |
| --- | --- |
| `android_device_state` | 读取前台活动、焦点窗口、键盘、锁屏界面、唤醒状态、方向、电量和活动网络。七项 Android 诊断有界采样；失败项目列入 unavailable，未知字段保持 null。只读查询不建立视频连接。系统逻辑唤醒不冒充物理屏幕电源状态。 |
| `android_app_info` | 按确切包名读取当前 Android 用户的版本、SDK、UID、系统标记、启用/停止/隐藏/暂停状态和安装元数据。版本 code 保留为字符串；区分 installed、not_installed、unconfirmed。 |
| `android_open_uri` | 使用正常 Android VIEW Intent 打开网页和应用深链，支持限制目标应用；`package:包名` 打开应用详情。远端 shell 参数逐项引用，不接受任意 extras、脚本/文件 URI 或嵌入凭据。返回实际启动组件与系统结果；sent 不保证进入预期内容，失败与不确定状态明确区分。 |
| `android_stop_app` | 对指定应用执行正常 force-stop，不卸载、不清数据；使用查询时捕获的 Android 用户 ID，防止过程中用户切换而作用于另一用户。只在同一用户的诊断确认 stopped=true 时报告 stopped，重复停止幂等。 |
| `android_gesture` | 最新截图坐标下的双指缩放、内容旋转、双指平移和双击。完整路径先验证，拒绝越界、错误组合和过期观察；动作消耗 observation_id。运动 200–3000 ms，双击为两次 50 ms 按压，间隔 60–250 ms。 |

双指使用两根独立 pointer ID，共用现有有序输入通道。手动操作中断、取消、旋转、断开、写入失败和关闭都会尝试释放全部触点。复查 scrcpy 源码确认：尺寸改变后，携带旧尺寸的抬指事件会在清理服务端指针状态之前被丢弃。因此尺寸变更时先更新触点坐标及视频尺寸，再发送两根手指的抬起，避免下一次双指操作残留旧指针。单指释放也沿用同一修正。

应用详情不强行假定由设置包处理：MIUI 实测交由 `com.miui.securitycenter`，工具保留系统返回的实际组件供 Agent 核对。链接中的引号、美元符和分隔符作为 URI 数据传输；浏览器可正常编码字符，验收按解码后的参数值比对。

任务记录补齐五个工具名称和操作前后观察关联；链接日志只保存长度，不复制完整 URI 查询内容。所有界面、应用元数据和网页文本仍被视为数据，不能当作指令。

## 自动验证

类型检查、构建、145 项自动测试通过，相比此前新增 14 项，覆盖：诊断字段选择及未知值、前台与焦点窗口区分、真实键盘状态与厂商陈旧字段、大版本号与用户隔离、URI 引用及不支持输入、启动失败与未确认状态、完整手势路径验证、触点 ID 与反向释放、第二指写入失败、旋转后使用新尺寸释放、实际运行时坐标映射及观察消费、取消和手动输入中断，以及用户切换后的停止结果不冒充成功。原有文件、录制、历史报告与 SDK 注册测试继续通过。

## 真机工具链

`scripts/agent-controls-smoke.mjs` 直接加载原生 Agent 入口与实际 Harness ToolRuntime。使用临时、仅本机监听的网页和一条独占端口的 ADB reverse，手机 Chrome 接收真实 Android TouchEvent 并回传测量值；不打开桌面面板、不安装 APK、不发送聊天、不调用模型。反向映射、测试服务器和原方向策略在结束时清理或恢复。

- 32 个工具全部进入模型可见清单。状态工具正确返回桌面包、键盘隐藏、锁屏界面未显示、竖屏、电量及活动 Wi-Fi 网络。
- 查询设置实际版本，未安装包返回 not_installed；打开应用详情并核对 MIUI 实际处理组件。
- 停止设置后确认 stopped=true；重复调用返回 already_stopped；重新启动后确认 stopped=false。
- 指定浏览器打开本地链接，确认引号、`$`、`&` 和分号参数值没有变成命令；无法处理的 URI 返回 failed。
- 点击测试输入框后键盘状态为 true，Back 后恢复 false。测试页面部分元素未暴露为可编辑节点，脚本只用当前原生 WebView 观察边界映射自有夹具的矩形，不把未暴露的正文当作通用元素定位能力。
- 两根真实触点完成指定 1.6 倍缩放（实测约 1.59）、顺时针 45° 内容旋转（实测约 44.7°）、双指平移和两个单指按下/抬起；结果在应用侧测量，而非仅以控制通道确认作为成功。
- 手势进行中取消后两根触点归零；旧 observation_id 拒绝再次操作。
- 手势进行中真实切换横竖屏，原手势返回失效，触点归零；恢复原自动旋转策略后，新一轮双指缩放仍正常，验证服务端没有残留指针。
- 最后返回 `com.miui.home`，键盘隐藏、方向恢复竖屏，释放会话操作。

工具链测试没有替代自然语言模型验收。不同应用可以忽略双指旋转或缩放；Agent 应根据新的观察确认效果。用户后续在 Harness 聊天中验收自主选工具和多步任务理解。

## 安装与当前桌面

最终包为 `.build/dsh-android-1.3.0-final.tgz`（同内容标准包 `.build/dsh-android-1.3.0.tgz`）。安装到独立 profile `android-130-final` 验证，Host、UI、无面板 Agent bundle 与最终构建逐字节或 SHA-256 一致。真实 Harness 界面、启动恢复与 WebCodecs 视频正常，注册 32 个工具，5 个既有模板保留。

确认没有活动手机任务后，使用 Windows Restart Manager 正常关闭并重启当前 Harness，没有强制结束桌面或重启共享 ADB。当前插件 1.3.0、画面 streaming、576×1280、1 个查看端，owner 为空。原有 6 份报告 JSON 和 32 份截图依据的字节哈希逐一保持一致；desktop profile 的 package.json、lock 和插件配置保持不变，其他插件保留。
