# 0.6.2 面板布局

移除面板内的 Android 标题，增加“手机 / 调试”标签页。连接、断开、返回、主页、最近任务和唤醒在手机画面右侧竖排，顶部对齐。视频参数、连接诊断、设置、任务记录和常用任务收在“调试”页。切换标签页保留视频连接，切回手机可直接继续操作。

已通过类型检查、构建和 70 项自动化测试。真机浏览器验收覆盖 360、480、860 像素宽度：右侧按钮纵向排列、顶部对齐、无横向溢出、无 Android 标题、主页面隐藏调试信息；手动主页、调试页诊断与模板读取、切回手机、断开重连正常。无浏览器未处理错误。

正式安装包在独立 profile 加载通过，15 个原生工具与 WebCodecs 视频正常。当前 Harness 桌面已正常重启加载 0.6.2，确认实时视频 576×1280，1 个查看端，新布局资源已加载。

证据：`.build/evidence/layout-smoke.json`、`layout-phone-360.png`、`layout-phone-480.png`、`layout-phone-860.png`、`layout-debug.png`、`unit-062.txt`、`release-smoke.json`、`desktop-062-delivery-health.json`。
