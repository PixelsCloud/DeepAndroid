# 0.7.0 结果交付

在现有 Harness 原生能力上增加 `android_save_result`，共 16 个原生工具。没有增加模型调用或任务循环。

## 功能

- 主界面增加“结果”标签页，显示最近 100 份结果。支持表格、摘要、部分完成与失败说明。窄面板表格可横向滚动，截图用弹窗查看。
- `android_read_list` 自动保存原始标题、可见行文字及截图引用，明确标为“原始采集”。Agent 通过 `android_save_result` 保存正式表格或摘要，明确标为“Agent 整理”，不冒充独立事实核实。
- 每行至少引用一个实际 `observation_id`；摘要通过顶层 `observation_ids` 引用。只能使用当前对话已保存的观察，不接受任意图片文件、网址或其他对话的依据。
- 未读到的单元格填 `null`。缺失字段或少于 `expected_count` 时自动改为部分完成；部分完成和失败需要原因。关联任务被取消、达到限额等情况会在界面及导出内容中保留。
- 可复制表格、下载 UTF-8 Markdown、带 BOM 的 CSV，以及包含报告、原始 PNG 和依据索引的 ZIP。Markdown 单文件不含截图原件，ZIP 中的相对截图链接可离线使用。CSV 和复制表格对公式前缀作中和处理，界面仍显示原始文字。
- 结果 JSON 独立持久化在数据目录 `results` 子目录。任务日志滚出列表不影响保存的结果与截图引用；附件原件仍由 Harness 持有。若原件被清理，文字仍可导出，截图和完整依据包明确报错。

单份最多 100 行、12 列、32 张截图、256 KiB 输入文字；依据包最多 48 MiB。相同工具调用 ID 重试不会重复保存。旧结果文件不自动删除。

## 验证

1. 类型检查、构建、82 项自动化测试通过。新增 12 项覆盖结构校验、缺失字段降级、UTF-8 大小、依据隔离、幂等保存、重启恢复、损坏文件提示、CSV/Markdown 转义、ZIP CRC 与实际解压、真实原生工具调用及 HTTP 导出与附件缺失。
2. 真机端到端：实际 Harness ToolRuntime 读取知乎 20 条，自动保存原始结果，再保存带依据的结构化表格。排名图标没有提供文字时保留空值，不调用模型猜测。手机最终回到桌面。
3. 实际浏览器结果页：显示 20 行与未读到字段；截图弹窗打开原始 PNG；复制表格成功；Markdown、CSV、ZIP 按钮下载成功。Python 校验导出 CSV 为 20 行，ZIP 无 CRC 错误且截图数与依据索引一致。
4. 服务重启后，结果内容及截图引用恢复；再次从结果页打开截图成功。宽、窄界面完成视觉检查，浏览器无未处理错误。
5. 既有手机布局、手动主页、标签页切换和断开重连回归通过。正式安装包在独立 profile `android-070-final` 加载成功，16 个工具与 WebCodecs 视频正常。
6. 当前用户桌面已正常重启加载 0.7.0，确认“结果”页资源、结果接口、576×1280 实时视频和 1 个查看端正常。用户桌面聊天留给用户自行验收，本轮没有代发聊天，也没有调用模型生成摘要。

证据位于 `.build/evidence`：`unit-070.txt`、`results-smoke.json`、`results-desktop.png`、`results-mobile.png`、`results-evidence.png`、`results-export.md`、`results-export.csv`、`results-export.zip`、`layout-smoke.json`、`release-smoke.json`、`desktop-070-delivery-health.json`、`release-070-sha256.json`。测试数据位于 `.build/tests`，不包含在安装包里。

## 聊天验收

“使用 Android 原生工具读取知乎热榜前 20 条，整理排名、标题和热度，调用 android_save_result 保存到结果页，expected_count 设为 20，关联实际截图。缺失字段留空并说明原因，最后返回桌面。”

完成后打开“结果”页核对表格、截图与导出文件。摘要任务也可保存到同一页面；整理质量仍由实际模型与页面可读取程度决定。
