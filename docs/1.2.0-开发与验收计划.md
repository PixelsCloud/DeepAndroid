# 1.2.0 历史复用与 scrcpy 常用能力

用户明确要求本轮全部完成：历史结果回读、文件互传与 APK 安装、音频、录屏、画面参数、剪贴板、音量、屏幕电源、旋转。继续采用 Harness 原生工具，不增加独立模型循环；手机页保持画面优先，扩展操作放更多操作或文件页。

## 交付项目

- [x] 原生历史搜索、读取、历史截图选择与来源引用，跨对话重新整理报告；历史引用不会成为手机操作坐标。
- [x] 手机文件列表、电脑到手机传输、手机到电脑下载、标准 APK 安装工具。文件往返通过，手机拒绝安装错误正确保留；成功安装补验待用户开启 USB 安装。
- [x] 双向文字剪贴板、音量/静音、屏幕亮灭、设备旋转；复用有序输入和观察失效机制，不增加控制权开关。旋转受应用和传感器限制，结果区分指令确认与方向变化。
- [x] 画面尺寸、帧率、码率配置；重连后应用，不丢失用户的主动断开选择。
- [x] scrcpy 音频转发、浏览器播放与音量，音频不可用不影响视频。浏览器播放由用户手势启动。
- [x] 视频/可用音频录制、停止与下载；有限时长/文件大小，断流保留已录片段。
- [x] 紧凑入口与文件页；进行中状态、安装错误、录制状态均可查看，不显示虚构百分比。
- [x] 130 项自动测试、浏览器测试，以及顺序执行的真机测试；不得同时运行会操作同一实体手机的测试。
- [x] 独立包安装验证、当前桌面正常重启更新、6 份原报告与 32 份截图依据校验通过。

## 实现约定

沿用当前固定 scrcpy server 5.0.1 与 Tango SDK；官方 v5.0.1 文档已核对。优先采用现有控制、音频与 ADB 接口。文件通过显式路径或用户选择的上传文件传输，HTTP 下载只开放插件记录中的文件标识，不开放任意本机路径。数据保存在插件数据目录，测试文件在独立测试目录。

历史报告读入当前任务时生成历史证据标识，保留原采集时间、设备和报告来源。仅由真实保存的报告建立证据引用，不把历史图片变成当前可点击观察。原报告和删除状态保持不变。

音频先采用 48 kHz 双声道 PCM 经 scrcpy 转发，前端使用 Web Audio。录屏优先保存原始 H.264 与可用 PCM 的 MKV，使用设备时间戳；设置时长、大小和写入积压上限，旋转或连接重建时结束当前片段并保留文件。使用 ffprobe/ffmpeg 校验真实产物，但不把 FFmpeg 作为插件运行必需依赖。

接口、测试数量及实际设备限制随实现记录在最终验收文档。不得把测试 Agent 回调或原始采集当作已经完成模型端语义验收。
