# 0.9.0 启动恢复与稳定性

修复客户端插件加载时侧栏尚未挂载导致 `openTab` 失败的问题。根据当前安装版 Harness 0.2.1-rc.2 的侧栏 API，订阅 `sidebarRight.mounted`，在会话组件的 React effect 中恢复；插件卸载或会话切换后忽略旧请求。已有其他展开页面时不抢占焦点。

新增 `panel-state.json`，原子保存内部页面、手机序列号、连接选择及启动恢复选项。旧安装没有该文件时使用默认值；损坏文件保留并在诊断中提示。部分更新顺序提交，不覆盖其他设置。

意外断流最多按 1、2、4 秒重试，稳定显示 10 秒后重置次数；明确断开会停止重试并持久化该选择。恢复时不更换已记住的手机，多台新设备需要明确连接。重连不重放操作，不恢复被取消的 Agent 任务。请求设有 30 秒超时；原有观察失效、任务限额与直接共享操作保持有效。

## 验证

- 类型检查、构建及 95 项自动测试通过。新增测试覆盖旧安装默认值、并发状态保存、损坏状态、字段验证、接口来源限制，以及复制备份后的旧结果、改名、最近删除、设置、模板、截图和导出。
- 实际 Harness 完整界面：独立安装 profile `android-090-final`，进入已有会话后无需点击 Android 即展开并显示真机画面；刷新恢复结果页；关闭自动展开后保持收起，手动入口仍可打开上次调试页。只选择已有会话，没有发送聊天消息或调用模型。
- 真机面板：重开复用采集连接；后端换端口重启后保留调试页和断开选择；模拟关闭本测试视频通道后自动连回同一台手机；注入连续 ticket 失败后停止重试；模拟原设备缺失时不误连其他设备；首次有多台设备时刷新也不隐式连接。
- 设置：原生工具按名称打开、聚焦中文搜索、读取“电池”结果、替换为“显示”、限定次数查找缺失目标、回桌面。
- 时钟：按名称打开、点击秒表页、读取“00:00.00 / 开始”等实际文字、保存带截图的结果、回桌面。没有启动计时或修改闹钟。
- 知乎：实际读取热榜 20 条，保存原始采集与整理结果，显示截图，复制表格，下载 Markdown / CSV / ZIP，并验证重启后仍可查看。元素未暴露的排名保留缺失并标为部分完成；未让模型补全数据。

证据位于 `.build/evidence`：`restoration-smoke.json`、`startup-shell-smoke.json`、`search-smoke.json`、`clock-smoke.json`、`results-smoke.json`、`unit-090.txt`。隔离数据在 `.build/tests`，不打入安装包。

备份验证包含截图原件的隔离测试目录；插件真实截图依赖 Harness 附件库，单独复制 JSON 不保证跨电脑可看图。本轮没有执行实体 USB 拔插，也没有替用户发送桌面聊天来验证模型规划。
